1. JSX is a syntax that lets us write HTML-like code inside JavaScript. It makes React code easier to write and understand.

2. Props are used to pass data from a parent to a child component. State is used to store and manage data inside a component.

3. useState is used to create and update component data. I used it to store and manage the technology stack data.

4. useEffect runs code after the component renders. I used it to load the JSON data when the project starts.

5. A unique key helps React identify each item in a list. It helps React update the list correctly and efficiently.

6. For example, I showed an empty stack message when there are no items in the stack.



7. A parent sends data to a child using props.
A child can send data back to the parent by calling a function passed through props.
